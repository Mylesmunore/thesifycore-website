# Thesify Core website

Responsive static website for Thesify Core, built with HTML, CSS and vanilla JavaScript.

## Publish with GitHub Pages

1. In **Settings → Pages**, set the source to **GitHub Actions**.
2. The included workflow deploys the site on pushes to main.
3. The custom domain is configured through the CNAME file. Add the appropriate GitHub Pages DNS records at your registrar and keep existing email/MX records.
